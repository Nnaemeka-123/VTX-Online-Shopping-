Cybersecurity Practice

Choose a safe exercise. These are local simulations, not real targets.

Exercise: Spot a phishing message

Look for urgency, mismatched sender, unusual link, requests for passwords or codes. Never enter real credentials into practice forms.

Exercise: Password safety

Learn about unique passwords, passkeys, MFA, password managers and recovery codes.

Exercise: Web security concepts

Learn how XSS, SQL injection, insecure access controls and CSRF work conceptually in intentionally vulnerable training environments.

Account Tracker & Security Check

Track your own accounts and public profile links. This tool does not log in, read private messages, track location, or access bank/WhatsApp data.

For a public-profile check, open the profile yourself and assess what is visible. Do not enter passwords, verification codes, banking PINs or recovery keys here.

WhatsApp Number Check

This tool cannot reveal chats, messages, contacts, online activity or private data from a phone number. It can help format a number and remind you to use WhatsApp's official app for any contact check.
